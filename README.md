# rfa-simulator

**An AI integrated Electronic Grid Simulator**

In this, you can create circuits using AI and calculate the parameters of an electronic grid — basically everything you need for simulation.

### How to Run This

1. Clone this repo:
   ```bash
   git clone https://github.com/ankush-anonymous/rfa-simulator-v2
   cd rfa-simulator-v2
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the simulator:
   ```bash
   npm start
   ```

And just like that, your locally simulated electronic grid simulator is ready!
